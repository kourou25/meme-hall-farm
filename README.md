# 欢欢农场 · 社区开源纪念版

农田、牧场、钓鱼、育肥、动态集市、租地、潜入及货仓攻防的现有前后端实现。2026-10-26 导出，保留本期玩法与停服结算实现。

## 内容

- src/farm：经营规则、库存批次、动态物价、交易、租地、守护、攻防、钱包事务与结算。
- src/routes/farm*.ts：Hono HTTP 接口。
- public/farm*.js、CSS 与 assets/farm：现有场景、操作界面、动画和素材。
- farm-entry.ts 与 farm-module.mjs：源码入口和可导入模块。
- schema.sql：空白的宿主集成结构，无生产数据。关联社区表用于描述接口依赖，不代表必须启用全部社区功能。
- data：当期玩法目录、全服行情和匿名汇总快照。没有逐用户存档、账号标识、钱包、私信、邀请、密钥或操作日志。

## 接入已有站点

1. 使用 Node.js 24 和包管理器安装 package.json 中的开发依赖，执行 npm run build。
2. 在 Cloudflare Workers / D1 的 Hono 应用中导入 farm；宿主须绑定 DB，并在调用前设置 c.set('user',已认证用户)。不得直接信任浏览器提交的用户ID。
3. 仅对空数据库使用 schema.sql；已有数据库请按各表差异建立迁移，禁止覆盖。
4. 对外挂载 farm 路由前实现身份鉴别、同源保护和站长判定；对接自有钱包时保留版本号、幂等收据和事务条件。src/services/auth.ts、src/farm/wallet.ts 是相应适配边界。
5. 静态资源复制到同源站点；通过 mountFarm(root,{userId,onLeave}) 挂载。onLeave 必须注册清理回调，路由退出时销毁画面与监听。
6. 项目忠实保留 2026-10-28 12:00（UTC+8）停服时间。作为新游戏复用前修改 src/farm/lifecycle.ts 的运营时间和补偿政策；不要在其他站直接沿用纪念赠币迁移。

本仓库是可集成的农场模块，不附带原社区登录凭据、部署域名控制权或生产数据库。配置项只有类型与占位说明。原站服务依赖应由部署方替换。

## 数据与资金

库存总量以 farm_saves 为准，market_lots 仅记录批次年龄与交易锁，不得相加。每次交易同时校验钱包、存档和报价版本；所有发放有唯一收据。停服补偿分批执行，已支付记录不可重复领取。当前数据是只读研究快照，不能导入为用户资产。
